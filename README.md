# m3 theme

pick a seed color, preview a material 3 color scheme and copy the flutter theme code.

- builds light and dark tonal-spot schemes from a seed with `@material/material-color-utilities`
- live phone preview (app bar, card, buttons, chips, fab)
- click any role swatch to copy its hex
- copy or download a `theme.dart` with `lightColorScheme`, `darkColorScheme`, `lightTheme` and `darkTheme`

everything runs in the browser.

```sh
npm install && npm run dev
```
